# Práctica Git - Clase 45

## Objetivo

Practicar ramas, stash, merge fast-forward, merge no-fast-forward y resolución de conflictos.

## Conceptos

- Rama:Es tomar un camino diferente al principal para realizar cambios sin afectar los principales.
- Commit:Registro de un avanze concreto. Usando una descripción detalla de la acción.
- Merge:Unión de dos caminos de trabajo.
- Stash:Guardar cambios temporalmente, cuando no estoy segura de confirmar.
- Fast-forward:Cuando la rama principal avanza cuando no se registran cambios paralelos.
- No-fast-forward:Cuando se unen dos historias y se realiza un commit de integración. 
- Conflicto: Un conflicto es un choque entre dos personas o entidades. No necesariamente implica un fracaso. Sino una manera de mejorar y conservar las cosas buenas.

## Mensaje de cierre
Desde tecnología y comunicaciones, la Semana 9 demuestra que levantar, proteger, diagnosticar, documentar y verificar una aplicación fortalece el proyecto y aumenta la confianza comunitaria.
